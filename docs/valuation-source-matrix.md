## Concrete implementation priorities supported by the evidence

1. Correct terminal reinvestment economics and cash-flow/rate labels before broader feature work (R1–R2, R10).
2. Build one complete operating-company workflow first; block unsupported financial/REIT/special situations with explicit rationale (R3–R4). These sources support financial-sector gating; a complete REIT/insurer method needs additional sector sources/data and must not be claimed implemented from this research alone.
3. Treat original source and retrieval mechanism as different fields; keep formula/input dependencies in saved/exported versions (R9, R13).
4. Evidence panel must say what is absent. Do not upgrade a linked document/hash to a claim that a metric/period was reconciled (R9, R13; product integrity inference).
5. Preserve analyst assumptions separately from actuals; avoid automatic intangible transformations or generic confidence percentages (R6–R8, R11).
6. Release assertions must separate deterministic correctness, retrieval quality, forecast performance and keyboard usability (R8, R12).

## Independent reference case and sensitivity caveat

For **next-year terminal NOPAT held fixed at 120**, WACC=10%, ROIC=10%:

- g=2% → reinvestment=24 → FCFF=96 → TV=96/(10%−2%)=1,200.
- g=4% → reinvestment=48 → FCFF=72 → TV=72/(10%−4%)=1,200.

This exact invariance requires holding next-year NOPAT fixed. If final explicit-year NOPAT is fixed and next-year NOPAT grows with g, a smaller remaining growth effect is expected. Do not write a false unconditional monotonicity or invariance test. Damodaran's HTML *Excess Returns and Terminal Value* page contains an apparent prose typo; the PDF R1's equation and ROC=WACC derivation are internally consistent and should be used.
