# FilingLens Phase 5 — Analyst decision memo and evidence register

Completed increment of the FilingLens six-phase feature sequence. The repository did **not** contain an approved Phase 5/6 roadmap when this increment began; this scoped release implements reviewable analyst synthesis without adding a seventh agent or inventing sources.

## Milestones delivered
1. Deterministically assemble an issuer-bound investment decision dossier from the existing analyzed filing, validated values, available citations and Phase 4 research queue. Document status is **draft** or **analyst_review_recorded**, never auto-approved investment advice.
2. Make analyst-authored thesis, counter-case, catalysts and optional notes editable in the browser. No user text is generated by a model or sent to the server.
3. Four explicit manual review declarations (financial figures, underlying sources, risks/counterevidence, valuation assumptions) are required alongside nonempty thesis/counter-case/catalysts before status can become **analyst_review_recorded**. Checking them does not authenticate source truth.
4. Build a bounded, deduplicated evidence register. Filing `excerpt` requires an exact quote and section. External `citation` requires a valid credential-free HTTPS URL and section; these are **not** classified as SEC-verified. No assumptions about accession numbers.
5. Export a self-describing JSON dossier on user request; no automatic database persistence, market-price guesses, fabricated recommendations or private filing transfer.

## Acceptance
- Typecheck, Vitest, build and PowerPoint smoke test green, followed by merge and Railway deployment verification.
- Tests reject malformed review declarations, oversized user input, insecure citations, absence of counter-case and overlarge inventories.
- Dossier is an **analyst-declared** record, not independently authenticated proof. It cannot close the outstanding live SEC CompanyFacts acceptance issue #52.

## Operator/user workflow
Run the ordinary analysis, inspect the Phase 3/4 evidence and decision drivers, complete Phase 5 fields and review checklist, then download the dossier JSON. The export contains notes and source excerpts; handle it as potentially sensitive local research data. It is not saved to the cloud unless the user independently uploads it.
